# Code of Conduct

## Our Standard

We are committed to making participation in ClientOps Tracker welcoming and respectful for everyone. Contributors are expected to:

- Be considerate and professional.
- Discuss ideas and implementation details in good faith.
- Accept constructive feedback.
- Focus on what is best for the project and its users.
- Respect different backgrounds, experiences, and viewpoints.

Unacceptable behavior includes harassment, discrimination, personal attacks, unwanted sexual attention, publishing private information, and deliberately disruptive conduct.

## Enforcement

Project maintainers may remove comments, close issues, reject contributions, or restrict participation when behavior violates this code. Report concerns privately through the security contact process in [SECURITY.md](SECURITY.md), or contact a maintainer through the repository's GitHub profile.

This code applies in project spaces and whenever an individual is representing the project.
