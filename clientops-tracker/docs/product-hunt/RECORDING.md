# Recording Script: Approximately 75 Seconds

Private recording rehearsal, light theme, fictional Northstar client, same
ticket as the gallery. Start signed in; hide browser chrome and never record
passwords, tokens, real inboxes or local desktop paths. Leave a visible
**0.2.0 preview / fictional example** caption.

| Time   | Screen / narration                                                                                                                                                                                                                                       |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0-10s  | Genuine app header with v3. "I'm Eden, the independent developer of ClientOps Tracker, an open-source support and delivery portal for small software agencies."                                                                                          |
| 10-25s | Original request, then scope revision 2 and comparison. "Northstar asks to find shipments by reference. The first proposal covered active shipments. The revised agreement includes active and archived shipments, with the earlier decision preserved." |
| 25-42s | Resolved ticket and delivery evidence. "The team resolves the ticket and ships release 1.5.0-demo. But delivery is not client acceptance. The reviewer still has a decision to make."                                                                    |
| 42-60s | Choose Request changes, type the fictional feedback, Send feedback. "Archived NS-0921 works, but active NS-1042 still fails. The client records exactly what remains unresolved against the agreed outcome."                                             |
| 60-70s | Refresh and show Changes requested. "The response persists. Scope approval, ticket resolution, release delivery and client acceptance remain separate facts."                                                                                            |
| 70-85s | Separate fictional walkthrough header or repository. "ClientOps is free MIT-licensed software. Assisted installation is a separate service. This is an unreleased preview, and the no-login example is clearly simulated."                               |

Add matching captions; speak naturally rather than speeding up to meet the range.
No public recording or upload was made. Do not replace the running UI with
Decision Journal concept art. Prepare another request with the fixture command
instead of deleting the previous feedback to fake a new decision.
