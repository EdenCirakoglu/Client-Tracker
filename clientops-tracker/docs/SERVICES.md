# ClientOps Tracker Services

Open-source support and delivery operations for small software teams, with a proposed assisted-installation service for teams that need help getting started.

**Availability:** booking and external checkout are not configured. This page describes the intended offer; it does not accept orders or promise a live hosted service.

Review materials: [first-customer interview, five-minute demo, usability task and
pricing worksheet](FIRST_CUSTOMER_PILOT.md). Effort estimates, support window,
price and terms are proposals awaiting owner approval, not a live quotation.

## One-Agency Installation Package

**Draft for owner approval, not an order form.** Intended buyer: one small software
agency that wants a private request-to-agreement-to-delivery record for its first
client project. The customer retains its own hosting, domain and provider accounts.
ClientOps remains free MIT software; the fee purchases the agreed work below.

| Included deliverable              | Completion evidence                                                                                                                                                                                               |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| One supported private environment | Approved digest-pinned API/web release, restricted runtime DB role, production-mode sessions and no demo shortcuts                                                                                                |
| Agreed environment configuration  | Trusted HTTPS/renewal, independent secrets, approved SMTP sender and actual test receipt                                                                                                                          |
| One agency/project onboarding     | Administrator, developer and named client reviewer complete one request, revised agreement and delivery decision                                                                                                  |
| Restore and operations check      | Encrypted off-host backup restored separately with decision intact; actual operator alert and compatible recovery procedure                                                                                       |
| Handover                          | Version/digests, private credential transfer, operator/user guides, update/backup responsibilities and signed acceptance record                                                                                   |
| Limited follow-up support         | Proposed **2 active hours within 14 calendar days of handover**, weekdays 09:00-17:00 Europe/Chisinau; initial response within 2 business days, not guaranteed resolution. Owner must approve capacity and terms. |

Prerequisites: a reviewed release, agreed written scope, provider eligibility,
approved budget and operator access through a private channel. Client data import,
custom development, extra environments/projects, integrations, rebranding beyond
the agreed logo, emergency/out-of-hours support and continuing maintenance are
excluded unless separately quoted. Hosting, domain, SMTP, backup storage and
monitoring bills are separate; see [current planning costs](PRIVATE_STAGING.md#provider-cost-check-16-november-2026).

Acceptance requires a working sign-in, request/agreement/delivery/decision journey,
tenant denial, restart/restore persistence, approved inbox receipt and operator
handover. Publishing a release or resolving a ticket is **not** client acceptance.
Until handover, Eden owns the agreed installation tasks; afterwards the named
customer operator owns hosting, backups, monitoring and upgrades unless a separate
maintenance agreement states otherwise. Record unresolved limitations explicitly.

No final price is approved. The [15-21-hour worksheet](product-hunt/QUOTE_WORKSHEET.md)
must be replaced with measured full-rehearsal effort before proposing a fixed fee.
Booking, payment and customer installation remain unavailable while these gates
are open. The existing public fictional walkthrough is an illustration, not a
writable demo, customer installation or evidence of commercial demand.

## Book a Demo

The planned walkthrough covers client requests, staff work queues, scoped project access, release-linked delivery, acceptance and progress summaries using fictional data. Discuss the team's workflow and installation requirements before agreeing a service.

**Booking is not open yet.** The maintainer must supply a public product/demo-booking URL. Do not post credentials, private customer records or infrastructure access in public issues.

## Buy Installation

The initial paid offer is **assisted installation**, not a licence to access the public code.

Proposed deliverables, subject to a written scope:

- One private deployment in the customer's agreed hosting environment.
- Application, domain/HTTPS, email and non-demo account configuration within the agreed scope.
- Agreed branding and onboarding for the team's administrators and client contacts.
- A handover covering access ownership, backups, updates and recovery responsibilities.
- Acceptance checks for login, organisation boundaries and the agreed ticket/delivery workflows.

Hosting/provider charges, ongoing support, data migration, custom integrations and new workflows are not included unless explicitly agreed. No uptime target, response-time commitment or launch date is implied by this page.

**Checkout is not open yet.** Price, currency, scope, terms and a tested external checkout URL must be supplied before purchases are enabled. Payment will be handled by an eligible external provider, not inside ClientOps. The service must describe exactly what is delivered and who owns ongoing operations.

## Other Options

- **Managed instance:** hosting, updates, backups, monitoring and defined support, offered only after real operational acceptance.
- **Custom implementation:** selectively scoped migrations, workflow changes and integrations.
- **Sponsor development:** optional support for open-source maintenance, separate from purchasing installation. No sponsorship destination is configured.
