# ClientOps Tracker Services

Open-source support and delivery operations for small software teams, with a proposed assisted-installation service for teams that need help getting started.

**Availability:** booking and external checkout are not configured. This page describes the intended offer; it does not accept orders or promise a live hosted service.

## Book a Demo

The planned walkthrough covers client requests, staff work queues, scoped project access, release-linked delivery, acceptance and progress summaries using fictional data. Discuss the team's workflow and installation requirements before agreeing a service.

**Booking is not open yet.** The maintainer must supply a public product/demo-booking URL. Meanwhile, the [local demo guide](../README.md#local-development) lets developers evaluate the software themselves. Do not post credentials, private customer records or infrastructure access in public issues.

## Buy Installation

The initial paid offer is **assisted installation**, not a licence to access the public code.

Proposed deliverables, subject to a written scope:

- One private deployment in the customer's agreed hosting environment.
- Application, domain/HTTPS, email and non-demo account configuration within the agreed scope.
- Agreed branding and onboarding for the team's administrators and client contacts.
- A handover covering access ownership, backups, updates and recovery responsibilities.
- Acceptance checks for login, organisation boundaries and the agreed ticket/delivery workflows.

Hosting/provider charges, ongoing support, data migration, custom integrations and new workflows are not included unless explicitly agreed. No uptime target, response-time commitment or launch date is implied by this page.

**Checkout is not open yet.** Price, currency, scope, terms and a tested external checkout URL must be supplied before purchases are enabled. Payment will be handled by an eligible external provider, not inside ClientOps. The service must describe exactly what is delivered and who owns ongoing operations.

## Other Options

- **Managed instance:** hosting, updates, backups, monitoring and defined support, offered only after real operational acceptance.
- **Custom implementation:** selectively scoped migrations, workflow changes and integrations.
- **Sponsor development:** optional support for open-source maintenance, separate from purchasing installation. No sponsorship destination is configured.
