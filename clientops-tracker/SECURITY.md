# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities in a public issue. Use a private GitHub Security Advisory for the `EdenCirakoglu/Client-Tracker` repository when that feature is available. Include the affected component, reproduction steps, impact, and any suggested mitigation.

If private advisories are unavailable, contact the repository owner through GitHub before making the issue public.

Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure.

## Scope

Security reports may include authentication bypasses, authorization failures, data exposure, injection vulnerabilities, dependency issues, secrets exposure, and unsafe deployment behavior.

For the implementation overview and known limitations, see [docs/SECURITY.md](docs/SECURITY.md).
